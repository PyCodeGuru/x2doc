# x2doc Stage 1 Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and demonstrate a tested local CLI/API vertical slice that converts one public single-image tweet through Syndication into a cached `Document` and deterministic Markdown output.

**Architecture:** A synchronous application service resolves the URL, reads or refreshes a versioned cache, invokes the Syndication fetcher, parses JSON and lossy plaintext blocks into Pydantic models, localizes media through a bounded async downloader, and renders Markdown into a deterministic output directory. Network, parser, cache, media, renderer, and CLI boundaries remain independently testable.

**Tech Stack:** Python 3.11+, Pydantic 2, httpx, tenacity, Typer, Rich, python-slugify, pytest, pytest-httpx, Ruff.
