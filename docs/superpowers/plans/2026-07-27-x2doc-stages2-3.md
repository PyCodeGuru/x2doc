# x2doc Stages 2–3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete x2doc from real X tweet/Article URLs through normalized Markdown, HTML, local media, cache, thread, and A4 PDF output.

**Architecture:** Keep routing, synchronous orchestration, fetchers, parsers, cache, media, and renderers separated by explicit contracts. A configurable fetch pipeline records every attempt; raw-kind-specific parsers normalize source data into `Document`. Playwright is the authenticated DOM boundary, while only media and thread fan-out use bounded asyncio.

**Tech Stack:** Python 3.11+, Pydantic, httpx, Typer/Rich, Playwright Chromium, markdown-it-py, pytest, pypdf, Ruff.
